# Kasimirs Kebab
a story game by Laupi_oida<br>
### Playable at: https://laupi-oida.itch.io/kasimirs-kebab
## What is it about?
You play Klaus a cool guy who wants an<br>
doner kebab but the kebab skewer was<br>
stolen and now you must find it
## Controls:
Arrow Keys -> Movement<br>
Z -> Action1/Yes<br>
X -> Action2/No<br>
<br>
The Controls can also be changed in the settings
